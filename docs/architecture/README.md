# Architecture Decision Records (ADRs)

This directory contains ADRs — short documents that capture important
architectural decisions, their context, and consequences.

## Format

Each ADR is a numbered markdown file:

```
# ADR-NNNN: Title

## Status
Accepted | Superseded by ADR-XXXX | Deprecated

## Context
What is the issue we're facing? What are the forces at play?

## Decision
What is the change we're making?

## Consequences
What becomes easier? What becomes harder?
```
